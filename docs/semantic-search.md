# Semantic Search — Embedding Model & Browser Inference

## Overview

The web viewer's 🧠 **Semântica** tab lets users search CNAE activities using natural language descriptions rather than exact keyword matches. For example:

- `"clínica veterinária"` → finds `"Atividades veterinárias"` even if the words don't overlap
- `"desenvolvimento de software"` → finds `"Desenvolvimento de programas de computador sob encomenda"`
- `"consulta médica"` → finds relevant healthcare subclasses

This is powered by **multilingual sentence embeddings** and **cosine similarity**, running entirely in the browser — no API key, no server.

---

## Architecture

```
Build time (Node.js)                    Query time (Browser)
─────────────────────────────           ─────────────────────────────────────────
npm run build:embeddings                User types in 🧠 Semântica tab
        │                                       │
        ▼                                       ▼
@xenova/transformers                    Transformers.js (CDN)
paraphrase-multilingual-MiniLM-L12-v2   paraphrase-multilingual-MiniLM-L12-v2
        │                                       │
2004 texts encoded                      Query text encoded
→ output/embeddings.json                → query vector (384-dim)
        │                                       │
        └─────────── inlined into ──────────────┘
                     web/index.html
                          │
                    cosine_similarity(query, all_2004_vectors)
                          │
                    top-20 results ranked by score
```

## Model Details

| Property | Value |
|----------|-------|
| Model ID | `Xenova/paraphrase-multilingual-MiniLM-L12-v2` |
| Original | `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` |
| Dimensions | 384 |
| Max tokens | 128 |
| Languages | 50+ languages (Portuguese fully supported) |
| Model size | ~120MB (quantized WASM, cached after first load) |
| License | Apache 2.0 |

This model was chosen for:
- **Strong Portuguese support** — trained on multilingual data including PT-BR
- **Small size** — runs efficiently in the browser without a GPU
- **Semantic quality** — good at matching descriptions of the same concept in different words

## Embeddings File (`output/embeddings.json`)

Generated by `npm run build:embeddings`. Contains one entry per CNAE record (2004 total):

```json
[
  {
    "codigo": "62.01-5",
    "titulo": "Desenvolvimento de programas de computador sob encomenda",
    "type": "classe",
    "embedding": [0.021, -0.043, 0.110, "..."]
  }
]
```

The `embedding` vector is computed from the record's `texto_embedding` field (see [Data Schema](data-schema.md)), which concatenates the full hierarchy most-specific-first.

### Regenerating Embeddings

Required whenever CNAE data changes:

```bash
npm run build:embeddings
# Takes ~2-5 minutes for 2004 records
# Writes output/embeddings.json (~5.6MB)

npm run web
# Rebuild viewer to inline the new embeddings
```

> The embeddings file is committed to the repo (~5.6MB) so the viewer works immediately after cloning without requiring users to re-run the embedding step.

## How Cosine Similarity Works

Given a query vector **q** and a stored embedding vector **v**, similarity is:

```
cosine_similarity(q, v) = (q · v) / (|q| × |v|)
```

The score ranges from -1 (opposite) to 1 (identical). In practice, CNAE scores range roughly from 0.3 (unrelated) to 0.9+ (very close match).

The viewer shows the **top 20 results** sorted by score descending.

## Browser Loading Behavior

On first use:
1. The model (~120MB quantized WASM) is downloaded from the Transformers.js CDN
2. It is **cached by the browser** for subsequent uses
3. A loading spinner is shown while the model loads and the query runs

After first use, queries are nearly instant (the model stays cached).

---

## Limitations

- **First load is slow** (~10-30s depending on connection) — model must download
- **128-token limit** — very long queries are truncated
- **Not exact** — semantic search ranks by similarity, not exact keyword presence. Use the regular text search tab for exact code or keyword lookups.
- **No re-ranking** — results are sorted purely by cosine score; no BM25 hybrid
